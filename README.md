# 🍔 DevBurger - Cardápio Digital

O **DevBurger** é um sistema de cardápio digital dinâmico e responsivo, desenvolvido para hamburguerias que buscam modernizar o atendimento e facilitar o processo de pedidos dos clientes. O projeto conta com uma interface limpa, seleção de itens em tempo real, validação de horários de funcionamento e integração com carrinho de compras.
<br><br>
🌐 **Acesse o projeto online:** [DevBurger na Vercel](https://vercel.app)

---

### 🚀 Funcionalidades
*   **Visualização de Produtos:** Listagem organizada de hambúrgueres e bebidas com preços e descrições.
*   **Carrinho Interativo:** Adição, remoção e cálculo do valor total dos pedidos em tempo real.
*   **Status de Funcionamento:** Verificação automática se o estabelecimento está aberto ou fechado com base no horário local.
*   **Finalização de Pedido:** Validação de endereço de entrega para envio dos dados.
*   **Design Responsivo:** Totalmente otimizado para navegação em dispositivos móveis e desktops.

---

### 🛠️ Tecnologias Utilizadas
A stack utilizada no desenvolvimento do projeto foi:
<br><br>
*   **HTML5:** Estruturação semântica da página.
*   **Tailwind CSS:** Framework utilitário para estilização rápida, moderna e responsiva.
*   **JavaScript (ES6+):** Manipulação do DOM, lógica do carrinho e validações do sistema.

---

### 📦 Como Executar o Projeto Localmente
<br>

1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```
<br>

2. **Navegue até a pasta do projeto:**
   ```bash
   cd DevBurger_Menu
   ```
<br>

3. **Instale as dependências (necessário Node.js instalado):**
   ```bash
   npm install
   ```
<br>

4. **Execute o ambiente de desenvolvimento (Tailwind):**
   ```bash
   npm run dev
   ```
   *(Ou abra o arquivo `index.html` diretamente no navegador caso não utilize o script de build para produção).*
